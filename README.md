# 知衡 · 中医（民间）治未病健康管理社区

## 一、项目愿景
本项目致力于打造一个去中心化的中医健康管理社区。连接顶尖的民间中医老师与患者，通过 AI 智能体辅助，实现“治未病”的日常健康管理，同时确保**数据主权归患者所有**。

## 二、技术栈
- **前端**：React + Vite + TypeScript
- **后端**：Python + FastAPI + LangGraph（规划中）
- **开发环境**：GitHub Codespaces

## 三、四大核心角色
1. **中医老师（真人）**：顶尖民间高手，负责审核签字，具有最终决策权。
2. **中医老师智能体（徒弟/助理）**：根据患者数据生成回复草案，辅助老师工作。
3. **患者（真人）**：社区核心，拥有完全的数据主权，自主管理病历。
4. **患者智能体（健康顾问/镜子）**：仅负责数据采集与上报，**绝不进行独立分析**。

## 四、核心机制与数据主权
- **封闭式邀请制**：老师拉患者入群，保证社区质量。
- **阅后即焚**：老师端不存储任何病历。老师阅读后，数据在后台自动擦除。
- **子午流注打卡**：结合中医时辰，患者在特定时间完成作业并打卡。
- **积分模拟系统**：用于支付学费或激励患者，数据存储于患者本地。
