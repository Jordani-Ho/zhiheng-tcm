## §1 施工顺序

### 1.1 两条线：主线 vs 独立项

E 板块施工分**两条线**，互不阻塞。

| 线 | 内容 | 依赖 | 推进方式 |
| :-- | :-- | :-- | :-- |
| **主线** | v0.4 第 1–5 章 + 第 8–10 章 | B/C/D 实现完成 | 串行推进 |
| **独立项** | v0.4 第 6 章（声诊）+ 第 7 章（切诊接口） | 无 | 可提前插入，不受主线阻塞 |

### 1.2 主线工程顺序（从 v0.4 §2.4 抽取）

**原则：先链后客户端。**

| 步 | 内容 | 阶段 | 可逆性 | 前置依赖 |
| :-- | :-- | :-- | :-- | :-- |
| 2.1 | 信任层四件上链（引荐链 / 封存记录 / 信誉数据 / 身份标识） | 阶段二 | IR-1/2/3/4 触发后不可逆 | B4 封存接口 + C 治理动作 + D 信任根分层 |
| 2.2 | 交易层两件上链（社区外交易映射 / 康币流转） | 阶段二 | 可逆（交易记录可标记作废，保留痕迹） | C §7 康币数据模型 |
| 2.3 | 本地 SQLite → 本地加密 + 链信任层 | 阶段二末 | 可逆（加密与不加密可切换） | B §3.1.4 tombstone + §3.4.4 同步友好性 |
| 2.4 | 智能体从后端迁移到客户端 | 阶段三 | 可逆（可回退到后端模式） | 2.1 + 2.2 + 2.3 完成 |
| 2.5 | 数据完全客户端本地，链只做信任层 | 阶段三 | 目标态，无回退必要 | 2.4 完成 |

### 1.3 不可逆窗口（从 v0.4 §2.3 抽取）

**IR-1 / IR-2 / IR-3 / IR-4 均在阶段二触发。** 阶段二是整个迁移中最需要谨慎的窗口。

| 不可逆点 | 触发条件 | 前置约束 |
| :-- | :-- | :-- |
| IR-1 引荐链上链 | 第一条引荐链写入链 | 阶段二前充分测试 |
| IR-2 封存记录上链 | 第一条封存记录写入链 | 阶段二前充分测试 |
| IR-3 身份标识上链 | 第一个身份公钥上链 | 阶段二前充分测试 |
| IR-4 信誉数据上链 | 第一条信誉事件写入链 | **阶段二启动前冻结信誉口径** |
