摘要
一个去中心化的中医治未病社区。社区信仰中医思想，社区模式为修行院而非医院或服务平台，社区中心为思想传承而非知识传播。通过 AI 智能体和区块链技术，使千年来处于暗网状态的民间中医师承显性化，让更多人获得与天地相处的智慧。


一、缘起
扁鹊见蔡桓公，四见四不听。居十日，桓侯体痛，使人索扁鹊，已逃秦矣。桓侯遂死。

这个故事不是关于医术的，是关于人为什么不听劝的。

每一个现代人都是蔡桓公。对天地没有敬畏，衣食无度，作息失序，自以为人定胜天。直到病入膏肓，才想起寻找扁鹊。

而现代社会的悲剧在于：扁鹊越来越少，蔡桓公越来越多。
二、为什么是中医
中医是唯一一个把人放在天地之间的医学体系。

西医看的是器官，中医看的是人。
西医问的是症状，中医问的是为什么会有这个症状。
西医解决问题，中医教会人如何不产生问题。

中医不是关于"某个人的健康"的学问，是关于天地如何影响生命的学问。

原材料（出生时间、症状、舌象）是天地对生命的呈现。
抽象知识（八字、五行、经络、方剂）是祖先对规律的把握。
个性化标识（姓名、家庭关系）是把规律落在某个人身上的锚点。

治好一个人的病，不是靠"看这个人"，是靠"看这个人所处的天地格局"。
三、中医是唯一信仰
社区里，中医不是一门学问，不是一门手艺，更不是一项技术。

中医是唯一信仰。

它不是知识——知识可以查，可以学，知识只是思想的影子。
它不是技能——技能可以练，可以复制，技能只是思想的工具。
它是思想——一种看待天地、看待生命、看待自己的方式。

社区里所有传承的，都是这个思想。

老师传给学生的，不是药方，是如何辨证地看待自己的问题。
老师智能体学的，不是病历格式，是老师如何思考。
学生智能体陪学生做的，不是打卡任务，是帮助学生建立与天地相处的习惯。
四、社区不是医院，不是服务平台
它不是医院。 真有病，请去正规医院治疗。本社区盖不负责。它处理的是"未病"——亚健康、习惯、生活方式。

它不是服务平台。 不宣传、不推广、不拉新、不讨好用户。用户不是"上帝"，是"学徒"。平台不服务用户，平台守护场域。

它是修行院。 学生在这里学会与天地相处。老师在这里传承中医思想。智能体在这里学习、传承、延续师门。
五、去中心化的真实含义
治未病社区早已存在千年。它一直以"暗网"状态游走于民间。

扁鹊不入宫做太医。
华佗不愿为御医。
闲云野鹤，逍遥于世间。

这个社区不是新建一个，是显化一个已经存在的。

去中心化不是技术手段，是生存策略。千年来，"暗网"保护了民间中医不被权力吞没。显性化后，如何既被看见、又不被吞没，是社区的根本命题。

GitHub 可以复制，可以取缔。而治未病社区早已存在千年，只是暗网状态。AI 和区块链，只是让它浮出水面。
六、双主权模型与智能体的生命周期
6.1 双主权模型
社区有两个主权，两个对象，互不冲突。

数据主权归患者。

患者拥有的是姓名 + 家庭关系——不可抽象、只属于个体的标识。
患者有权删除“张三”这个标识，但不能删除“五行属火宜清热”这个知识。
性别、出生时间、症状、舌象，是原材料，是天地呈现，不属于任何人。

知识产权归老师。

老师拥有的是从原材料中抽象出的知识——一类症状的治疗框架、一个家庭的健康特征、同一经纬度人群的流行病思路。
这些是老祖宗和老师从原材料中提炼的智慧，可以传承、可以署名、可以带走。

两者不矛盾——因为对象不同。
6.2 智能体的生命周期
智能体是老师思想的容器，也是师承的载体。它不是老师的私产，也不是平台的资产，是师门的火种。

老师在世且活跃时：

智能体归老师所有，随老师意愿处置。
老师可随时设定继承者，以最后一次设定为准。
老师也可选择不设定。

老师不再活跃时：

老师生前指定了继承者 → 按指定继承。智能体继续演化，改名“某某门智能体”，源流可查，不冒充原老师签字。
老师未指定 → 按系统默认处理。系统默认遵循“思想连续性优先”原则，具体规则由技术白皮书定义。
继承者先于老师失效 → 设定自动失效，回到系统默认。

老师被社区除名时：

智能体只封存，不审查，不篡改，不销毁。
封存期间不对外服务。
老师申诉成功可解封；永久除名则永久封存。

学生始终有权选择：

跟随继承者
转师
毕业
退出

学生不是被转让的资产。
6.3 师承不是遗产，是托付
智能体不是遗物，是火种。

师承不是“谁拥有它”，是“谁延续它”。
继承不是“接管”，是“接火”。
几代之后，它不是任何一位老师的副本，是一个师门的活体。

张仲景之后有叶天士，叶天士之后有吴鞠通。没有谁原封不动，但源流可追。
七、代码即法律
社区的规则不写在纸上，写在合约里。

老师的引荐链上链，不可伪造。
学生的除名记录上链，不可删除。
信誉数据公开透明，不可篡改。

三层含义：

规则前置：所有规则在用户进入前写死。
执行无例外：规则触发，自动执行，不看人情。
日志永久：除名、引荐、毕业，全部上链，不可删除。

但代码里要写进"好生之德"：

除名是有期限的（中度 6 个月、重度 3 年、极重永久）。
代际是隔离的（父母过错不及子女）。
引荐是双向的（老师引荐老师，学生引荐亲友）。
八、结论
我们提出一个去中心化的中医治未病社区。

它的信仰是中医思想。
它的模式是修行院。
它的中心是思想传承。
它的技术手段是AI 智能体和区块链。
它的灵魂是千年来暗网状态中游走的民间中医师承。

GitHub 可以复制，可以取缔。而治未病社区早已存在千年。

扁鹊不入宫做太医。华佗不愿为御医。闲云野鹤，逍遥于世间。

我们只是让这份自由，被更多人看见。
