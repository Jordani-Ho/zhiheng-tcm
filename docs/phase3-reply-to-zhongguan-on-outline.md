**① 额度从设计上就是学生专属**

`referral_service.py:71–74` 逐字（`create_student_referral` 的 docstring）：

→ **老师引荐路径的 docstring 里，「额度」两个字一次都没出现。**

**② 唯一的额度校验代码只服务学生路径**

`referral_service.py:88–96`：

```python
db = _db()

target_year = int(year) if year is not None else datetime.now().year

        "create_student_referral：引荐人 %r 在 %d 年的引荐额度已满（%d/%d）"
```

**③ `count_referrals_by_referrer_in_year` 是名不副实的遗留物**

它按 `referrer_id` 计数，**不区分被引荐人类型**（就叫 referrer，不带 `referee_type` 过滤）。名字之所以含糊，正是因为**当初两类引荐共用**——**这恰是它是学生引荐遗物的证据**，不是「老师引荐额载体」的证据。
